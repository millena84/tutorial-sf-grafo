# tutorial-sf-grafo

Site publicado do **sf-tutor**: um tutorial visual e navegável, em grafo, do ecossistema Salesforce (funcionalidades, metadata types, objetos API, propriedades e campos, com fontes oficiais citadas).

- **Endereço:** https://millena84.github.io/tutorial-sf-grafo/ (GitHub Pages, branch `main`, pasta `/docs`).
- **Origem:** o conteúdo de `docs/` é **gerado**: é o build de `apps/sf-tutor` no repositório de trabalho (privado), feito a partir da base de insumos validada. Não edite `docs/` à mão; cada versão entra por PR.
- **Versão:** `docs/data/build-info.json` informa o commit dos insumos e a data do build. `docs/data/manifest.json` informa o contrato de dados e a versão da API Salesforce de referência.

Projeto independente, sem afiliação com a Salesforce, Inc. Salesforce é marca da Salesforce, Inc.
